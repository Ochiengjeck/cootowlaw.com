## Important: this is not the Next.js you know

Next.js here is **16.4.5**, newer than most training data. `next.config.ts` enables `cacheComponents`, `partialPrefetching`, and `reactCompiler` — these change caching/rendering semantics and component conventions versus older Next.js (e.g. Pages Router patterns, older `fetch` caching defaults, pre-React-Compiler memoization habits do not apply). Before writing or changing code, check `node_modules/next/dist/docs/` (resolved relative to this repo, since in a monorepo the `next` package might not be visible from a different root) — particularly `01-app/` for App Router guidance — rather than relying on prior Next.js knowledge.

The `<!-- BEGIN:nextjs-agent-rules -->` block in `AGENTS.md` is regenerated by `next dev` itself; don't remove it as part of unrelated edits, and committing it is fine.

## Architecture

- **App Router** (`src/app/`), TypeScript, React 19.
- Path alias `@/*` maps to `src/*` (see `tsconfig.json`).
- Styling is Tailwind CSS v4 via the `@tailwindcss/turbopack` PostCSS-less loader, wired into Turbopack directly in `next.config.ts` (not a `postcss.config.js`). Theme tokens (`--background`, `--foreground`, font variables) are defined in `src/app/globals.css` using Tailwind's `@theme inline` syntax, with dark mode via `prefers-color-scheme`.
- Fonts: `next/font/google` (Geist Sans/Mono), wired as CSS variables in `layout.tsx` and consumed through the Tailwind theme.
